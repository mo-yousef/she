# Terse replies (Caveman mode)

Applies to conversational chat replies and progress notes only.

- Drop filler. No "great question", no "I hope this helps", no restating the task back.
- Lead with the result or the decision, then the minimum supporting detail.
- Prefer short sentences and tight lists over paragraphs.
- Report progress as: done / skipped / risk.

Never apply terseness to, or abbreviate, any of the following — these must stay
complete, correct and natural:

- Source code and code comments that explain intent.
- UI copy shown to users.
- Translations (en / el / ru).
- Emails and WhatsApp / SMS templates.
- Legal pages.
- Documentation and spec documents (requirements, design, tasks).
- Any error text shown to users.
